# Local national flag assets

Source: https://github.com/lipis/flag-icons, version 7.3.2 (MIT; see LICENSE).
Archive: https://registry.npmjs.org/flag-icons/-/flag-icons-7.3.2.tgz
Archive SHA-256: 9477c5252afe0e99dd2d4408b664c83e7c7c80785c7983751d5c7a020198a731

Only the 195 playable countries' 4x3 SVG assets are bundled. No package was
installed. No library CSS, JavaScript, fonts or runtime CDN is used.

The explicit canonical-ID to ISO alpha-2 mapping is src/flags/countries.json.
Names were matched against the source country.json; explicit reviewed mappings
cover naming variants, Holy See, the Congos, Koreas, Palestine, UK and US.
manifest.json records every canonical mapping and exact asset SHA-256.
The source SVG bytes are unchanged. Image rendering uses img, never SVG injection.
Images contain no scripts, event handlers, foreignObject or external references.

These are source-library flag representations at this pinned version, not a
claim of legal or diplomatic recognition. Special shapes remain in their source
4x3 canvas. The poster uses object-fit:contain to avoid cutting off their designs.
A failed or missing asset becomes a labelled non-flag fallback.
